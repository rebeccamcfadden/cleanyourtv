Send to TV

Copy these two into the Send to TV Shortcut on this iPhone. Then share a watch-list note to it from Notes or Keep.

No pairing code in this link: scan the QR in the TV's Launcher settings → Phone notes again.

  1. In Shortcuts, make a shortcut named Send to TV; in its details turn on Show in Share Sheet (Text and Notes).
  2. Add Get Text from Input, then Text with your list's name, e.g. Rebecca.
  3. Add Get Contents of URL: paste the address, Method POST, a header Authorization with the value above, and a JSON body with list (the Text) and text (the note's text).
  4. Add Get Dictionary Value for message, then Show Notification.

The code stays on this phone: it is in the link after the #, which is never sent to the TV.
