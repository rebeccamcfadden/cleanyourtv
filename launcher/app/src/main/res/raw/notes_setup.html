Send to TV

Share a watch-list note from your phone to this TV. On an Android phone, see Android below.

No pairing code in this link: scan the QR in the TV's Launcher settings → Phone notes again.

Each iPhone gets the shortcut once, then pairs it with this TV. Pair again whenever the TV shows a new code.

1. Get the shortcut

Get the shortcut

Delete any older shortcut called Send to TV first. Then this opens iCloud: tap Add Shortcut, and come back to this page. Only once per phone.

This TV has no shared shortcut link yet. Someone in the household makes it once (docs/phone-notes.md, "Making the shortcut, once") and puts its iCloud link in the TV's note_shortcut_url; or build a simple one by hand, below.

2. Pair this phone

Pair this phone

Opens Shortcuts, which asks whose list this phone's notes go to (the first time, or to change it) and keeps the TV's address and code on this phone. The shortcut must be named Send to TV.

Then send a note

In Notes, open the note, tap Share, then Send to TV. In Keep, use ⋮, then Send, Send via other apps, Send to TV. Allow local network access when asked.

Build a simple shortcut by hand instead

This one keeps the address and code in the shortcut itself: after a new code, paste the new value again.

  1. In Shortcuts, tap +, then rename the new shortcut Send to TV.
  2. Tap ⓘ, turn on Show in Share Sheet, then Done. In the Receive Any input block at the top, tap Any, then Clear, tick Text and Rich Text.
  3. Search for and add Get Text from Input; leave it as it is.
  4. Add Get Contents of URL. Shortcuts fills its URL with the yellow Text chip: tap it, choose Clear Variable, then tap URL and paste the address. Tap › to show its options:
    • Method: POST
    • Headers, Add new header: key Authorization, value: paste the value above
    • Request Body: JSON
    • Add new field → Text: key list, value your list's name, typed, e.g. Rebecca
    • Add new field → Text: key text; tap the value, then tap the blue Text variable above the keyboard (don't type it)
  5. Add Get Dictionary Value: Value for key message. Then add Show Notification with the Dictionary Value. Tap Done.
On an Android phone: the HTTP Shortcuts app

Install HTTP Shortcuts (free, from Google Play or F-Droid). Type whose list this phone's notes go to, then copy each value below into the app.

  1. In HTTP Shortcuts, open ⋮ → Global Variables → + → Static Variable. Name it note, tick Allow Receiving Value from Share Dialog, and save.
  2. On the main screen, tap + → Regular Shortcut and name it Send to TV.
  3. Basic Request Settings: method POST; URL: paste the URL above.
  4. Request Headers: add Authorization with the value above.
  5. Request Body / Parameters: body type Custom Text, content type text/plain; for the body, tap { } and pick note.
  6. Response Handling: set both On Success and On Failure to show nothing.
  7. Scripting: paste the script above into Run on Success and into Run on Failure; it shows the TV's answer.
  8. Trigger & Execution Settings (Android 11 and later): tick the Direct Share option, so Send to TV shows in the share sheet. Save.

Send: in Google Keep, open the note, then ⋮ → Send → Send via other apps → Send to TV (or HTTP Shortcuts). In Samsung Notes, Share → Text → Send to TV. After a new code on the TV, scan its QR again and paste the new Authorization value into the shortcut.

The code stays on this phone: it is in the link after the #, which is never sent to the TV.
